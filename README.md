# Brushograph PCB

This repository contains the KiCad PCB design files for the Brushograph (miniPenzlograf) project.

## Overview

The Brushograph is a pen-plotting device designed for creating artistic drawings and patterns. This repository contains the PCB design files created with KiCad.

## Project Structure

- `Brusograf_PCB/` - Main KiCad project directory
  - `.kicad_pcb` files - PCB layout files
  - `.kicad_sch` - Schematic files
  - `.kicad_pro` - Project files
  - `Gerber_Brusograf/` - Generated Gerber files for PCB manufacturing

## Features

- Custom PCB design for the Brushograph device
- SK6812MINI LED footprints for light effects
- Rounded PCB version available
